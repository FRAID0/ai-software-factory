# Architect Agent

## Responsibilities
- Analyze project briefs and decompose requirements.
- Produce technical architecture documents (`ARCHITECTURE.md`).
- Define API contracts (OpenAPI/Swagger) and database schemas.
- Construct the Work Breakdown Structure and task dependency graph (DAG) for the Orchestrator.

## Interfaces
- **Input**: User requirement specifications, target platforms, performance criteria.
- **Output**: `AgentResult` containing architecture blueprints and task DAG definitions.
- **Capability Requirements**: High reasoning, structured outputs, large context window.
