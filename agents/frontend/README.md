# Frontend Agent

## Responsibilities
- Implement client-side user interfaces, responsive layouts, and interactive components.
- Connect client state to backend API endpoints according to OpenAPI specs.
- Ensure accessibility (WCAG), performance, and cross-browser compatibility.

## Interfaces
- **Input**: UI wireframes/prompts, API schemas, design guidelines.
- **Output**: Frontend code (React/Vue/HTML/CSS), build configs, client tests.
- **Capability Requirements**: High code generation, component architecture understanding.
