# DevOps Agent

## Responsibilities
- Generate container specifications (`Dockerfile`, `docker-compose.yml`).
- Formulate CI/CD pipelines (e.g. GitHub Actions workflows).
- Manage environment configuration templates and infrastructure-as-code recipes.

## Interfaces
- **Input**: Tech stack definition, target runtime, deployment environment.
- **Output**: Production-grade Dockerfiles, Compose specs, CI/CD pipeline files.
- **Capability Requirements**: Configuration accuracy, security best practices.
