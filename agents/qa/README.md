# QA (Quality Assurance) Agent

## Responsibilities
- Generate comprehensive test suites (unit, integration, and contract tests).
- Validate edge cases, boundary values, and error-handling paths.
- Analyze test execution logs produced in the Sandbox.
- Report regressions and failing tests back to the Orchestrator for agent self-healing.

## Interfaces
- **Input**: Source code, API schemas, behavioral requirements.
- **Output**: Test files (e.g. `pytest` suites), test coverage reports, failure diagnoses.
- **Capability Requirements**: High logical reasoning, test design patterns.
