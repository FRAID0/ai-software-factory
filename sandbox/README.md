# Sandbox Subsystem

The **Sandbox** provides an isolated, audited, and resource-bounded execution boundary for running code and test suites generated by AI agents.

## Core Security Safeguards
1. **Isolated Runtime**: Execution occurs in ephemeral, disposable container environments.
2. **Resource Throttling**: Strict memory (default: 512 MB), CPU (default: 1 core), and execution timeout (default: 30s) caps.
3. **Network Isolation**: By default, `--network none` is enforced to prevent unauthorized data exfiltration or reverse shells.
4. **Credential Isolation**: Host secrets and LLM API keys are NEVER mounted or passed into sandbox containers.
5. **Read-Only Root Filesystem**: Writes are restricted strictly to an ephemeral workspace directory.
